# Hospital Data Analysis Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze hospital data and provide meaningful insights into hospital operations and performance.

## Tools & Technologies

- Power BI
- Power Query
- DAX

## Key Features

- KPI cards for important hospital metrics
- Interactive charts and visualizations
- Slicers and filters for data exploration
- Data cleaning and transformation using Power Query
- Relationships between multiple tables
- Hospital performance analysis

## Key Insights

- Analyzed hospital data using interactive dashboards
- Identified important trends and patterns
- Created DAX measures for key performance indicators
- Presented insights through interactive Power BI visualizations
